Exemplo 32 -Exercício de Aplicação de Classes

Instruções

Neste exercio você deverá praticar a aplicação de classes CSS nos elementos HTML.

Utilize as classes disponveis no arquivo estilos.css para modificar a aparência dos textos abaixo.

Você deverá experimentar as classes destaque,cursiva,italico,sublinhado ,azul,negrito e google

Lembre-se de que é possivel utilizar mais de uma classe no mesmo elemento

Part 1- Aplicando uma classe

O HTML é uma linguagem utilizada para criar a estrutura das páginas da internet.
O CSS é utilizado para definir a aparência dos elementos,como cores,tamanhos e tipos de fontes.
Aplique uma classe diferente em cada parágrafo acima.

Part 2- utilizando mais de uma classe

As classes podem ser combinadas para criar diferentes efeitos visuais.Por exemplo,uma palavra pode ficar azul e em negrito. Outra palavra pode ficar italica e sublinhada. Agora escolha outras palavras deste texto e aplique duas ou mais classes ao mesmo tempo.

Parte 3-Trabalhando com fontes

A escolha da fonte pode alterar completamente a aparê de um texto. A classe destaque utiliza uma fonte diferente e aumenta o tamanho do texto. A classe cursiva apresenta o texto com um aparência semelhante à escrita á mão. A classe google possui uma fonte que pode ser personalizada pelo aluno no arquivo estilo.css
